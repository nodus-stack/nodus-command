# `noduscm up --tunnel` (ngrok) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `noduscm up --tunnel [--tunnel-url <url>]` exposes the local WordPress through an ngrok tunnel, rewrites `WP_HOME`/`WP_SITEURL` for the run, and restores them afterwards.

**Architecture:** A small `tunnel.js` module owns the ngrok process (behind a one-entry `PROVIDERS` map). `wordpress.js` gains a marker-delimited URL block plus `applyWpUrl` so only those lines are rewritten (salts untouched). A state file `.noduscm/tunnel.json` makes restoration precise, including after a hard kill. `up` runs the tunnel session in the foreground; `down` and plain `up` restore stale state.

**Tech Stack:** Node.js 18+ ESM, `execa` ^8, `fs-extra`, `commander`, `chalk`, `ora`, `vitest`.

**Spec:** `docs/superpowers/specs/2026-09-19-up-tunnel-design.md`

## Global Constraints

- ESM only (`"type": "module"`); no new dependencies.
- Provider scope: **ngrok only** in this version. Do not add cloudflared/devtunnel code.
- Marker strings, exact: `// nodus:url-start` and `// nodus:url-end`.
- State file, exact: `.noduscm/tunnel.json` (via `paths.noduscm`).
- Dedicated tunnel port, exact: `8088` (`"8088:80"`), only for Traefik compose variants and only when `up` runs with a tunnel.
- ngrok command, exact: `ngrok http <port> [--url <url>] --log=stdout --log-format=json`.
- Discovery timeout: 30 s.
- `--tunnel-url` must be an `https://` URL; it implies `--tunnel`; it wins over `tunnel.url` in `.noduscm.json`; `tunnel.url` is only used when a tunnel flag is present.
- Artifacts (code, comments, docs, messages) in English.
- Run tests with `./node_modules/.bin/vitest run` (plain `pnpm test` also works after `pnpm install`).
- **Git policy (overrides the usual "commit" step):** never commit, push, or add a `Co-Authored-By` line unless the maintainer explicitly asks. Each task ends with a checkpoint (tests green), not a commit. The version bump (`npm version minor` → 1.4.0) is done by the maintainer at release time.

```js
export const URL_BLOCK_START = '// nodus:url-start';
export const URL_BLOCK_END = '// nodus:url-end';

const FORWARDED_PROTO_SNIPPET = `if ( isset( $_SERVER['HTTP_X_FORWARDED_PROTO'] ) && 'https' === $_SERVER['HTTP_X_FORWARDED_PROTO'] ) {
    $_SERVER['HTTPS'] = 'on';
}`;

function buildUrlBlock(url) {
  return `${URL_BLOCK_START}\ndefine( 'WP_HOME', '${url}' );\ndefine( 'WP_SITEURL', '${url}' );\n${URL_BLOCK_END}`;
}

function escapeRegExp(value) {
  return value.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

const BLOCK_PATTERN = new RegExp(`${escapeRegExp(URL_BLOCK_START)}[\\s\\S]*?${escapeRegExp(URL_BLOCK_END)}`);
const WP_HOME_LINE = /^[ \t]*define\(\s*['"]WP_HOME['"].*\r?\n?/m;
const WP_SITEURL_LINE = /^[ \t]*define\(\s*['"]WP_SITEURL['"].*\r?\n?/m;
const REQUIRE_LINE = /^[ \t]*require_once\s+ABSPATH\b.*$/m;

export function rewriteWpUrl(content, url) {
  const block = buildUrlBlock(url);
  let result;

  if (BLOCK_PATTERN.test(content)) {
    result = content.replace(BLOCK_PATTERN, () => block);
  } else if (WP_HOME_LINE.test(content)) {
    // Drop the legacy WP_SITEURL first: the new block also contains a WP_SITEURL line.
    result = content.replace(WP_SITEURL_LINE, '').replace(WP_HOME_LINE, () => `${block}\n`);
  } else if (REQUIRE_LINE.test(content)) {
    result = content.replace(REQUIRE_LINE, (line) => `${block}\n${line}`);
  } else {
    throw new Error('Cannot update wp-config.php: no WP_HOME block and no "require_once ABSPATH" line found');
  }

  if (!result.includes('HTTP_X_FORWARDED_PROTO')) {
    result = result.replace(BLOCK_PATTERN, (matched) => `${matched}\n${FORWARDED_PROTO_SNIPPET}`);
  }

  return result;
}

export async function applyWpUrl(wpConfigPath, url) {
  const current = await fs.readFile(wpConfigPath, 'utf8');
  const next = rewriteWpUrl(current, url);

  if (next !== current) {
    await fs.writeFile(wpConfigPath, next);
  }
}
```

```js
const TEMPLATES_PUBLISHING_APACHE = ['docker-compose-windows.yml', 'docker-compose-podman-simple.yml'];

export function selectComposeTemplate(config, engine, platform = process.platform) {
  const useRemoteDb = config.database.type === 'remote';

  if (platform === 'win32') {
    return 'docker-compose-windows.yml';
  }

  if (engine === 'podman' && !useRemoteDb) {
    return 'docker-compose-podman-simple.yml';

export function getTunnelTargetPort(config, engine, platform = process.platform) {
  const templateName = selectComposeTemplate(config, engine, platform);

  if (TEMPLATES_PUBLISHING_APACHE.includes(templateName)) {
    return Number(config.localApachePort) || 8080;
  }

  return TUNNEL_FALLBACK_PORT;
}

function buildApacheTunnelPortsYaml(tunnel, templateName) {
  if (!tunnel || TEMPLATES_PUBLISHING_APACHE.includes(templateName)) {
    return '';
```

```js
import { execa } from 'execa';

const START_TIMEOUT_MS = 30000;
const OUTPUT_TAIL_CHARS = 500;

export function parseNgrokUrl(line) {
  let entry;

  try {
    entry = JSON.parse(line);
  } catch {
    return null;
  }

  if (entry?.msg !== 'started tunnel' || typeof entry.url !== 'string') {
    return null;
  }

  return entry.url.startsWith('https://') ? entry.url : null;
}

export const PROVIDERS = {
  ngrok: {
    binary: 'ngrok',
    installHint: 'Install ngrok from https://ngrok.com/download and run "ngrok config add-authtoken <token>".',
    buildArgs: ({ port, url }) => [
      'http',
      String(port),
      ...(url ? ['--url', url] : []),
      '--log=stdout',
      '--log-format=json'
    ],
    parseUrl: parseNgrokUrl
  }
};

function buildExitError(provider, result, outputTail) {
  if (result?.code === 'ENOENT') {
    return new Error(`${provider.binary} was not found in PATH. ${provider.installHint}`);
  }

  const detail = outputTail.trim() ? `\n${outputTail.trim()}` : '';
  return new Error(`${provider.binary} exited before the tunnel was ready.${detail}`);
}

export async function startTunnel({ provider = 'ngrok', port, url, timeoutMs = START_TIMEOUT_MS, spawn = execa }) {
  const definition = PROVIDERS[provider];

  if (!definition) {
    throw new Error(`Unsupported tunnel provider: ${provider}`);
  }

  const child = spawn(definition.binary, definition.buildArgs({ port, url }), { reject: false });
  const exited = Promise.resolve(child);
  let outputTail = '';

  const remember = (chunk) => {
    outputTail = (outputTail + String(chunk)).slice(-OUTPUT_TAIL_CHARS);
  };

  child.stdout?.on('data', remember);
  child.stderr?.on('data', remember);

  const publicUrl = await new Promise((resolve, reject) => {
    let buffer = '';

    const onData = (chunk) => {
      buffer += String(chunk);
      const lines = buffer.split('\n');
      buffer = lines.pop();

      for (const line of lines) {
        const found = definition.parseUrl(line);

        if (found) {
          settle();
          resolve(found);
          return;
        }
      }
    };

    const timer = setTimeout(() => {
      settle();
      child.kill();
      reject(new Error(`${definition.binary} did not report a public URL within ${Math.round(timeoutMs / 1000)}s`));
    }, timeoutMs);

    function settle() {
      clearTimeout(timer);
      child.stdout?.off('data', onData);
    }

    child.stdout?.on('data', onData);

    exited.then((result) => {
      settle();
      reject(buildExitError(definition, result, outputTail));
    });
  });

  return {
    url: publicUrl,
    exited: exited.then(() => undefined),
    async stop() {
      child.kill();
      await exited;
    }
  };
}

function normalizeTunnelUrl(value) {
  let parsed = null;

  try {
    parsed = new URL(value);
  } catch {
    parsed = null;
  }

  if (!parsed || parsed.protocol !== 'https:') {
    throw new Error(`--tunnel-url must be an https:// URL (received "${value}")`);
  }

  return parsed.origin;
}

export function resolveTunnelOptions(options = {}, config = {}) {
  const enabled = Boolean(options.tunnel || options.tunnelUrl);

  if (!enabled) {
    return { enabled: false, url: null };
  }

  const rawUrl = options.tunnelUrl || config.tunnel?.url || null;

  return { enabled: true, url: rawUrl ? normalizeTunnelUrl(rawUrl) : null };
}
```

```js
export function getTunnelStatePath(paths) {

export async function writeTunnelState(paths, state) {
  await fs.ensureDir(paths.noduscm);
  await fs.writeJson(getTunnelStatePath(paths), state, { spaces: 2 });

export async function clearTunnelState(paths) {
  await fs.remove(getTunnelStatePath(paths));

export async function hasTunnelState(paths) {
  return fs.pathExists(getTunnelStatePath(paths));
}

export async function restoreLocalUrl(config, paths) {
  const wpConfigPath = path.join(paths.wordpress, 'wp-config.php');

  if (await fs.pathExists(wpConfigPath)) {
    const localUrl = getLocalSiteUrl({
      domain: config.domain,
      engine: config.engine,
      localApachePort: config.localApachePort,
      localHttps: config.localHttps,
      localHttpsPort: config.localHttpsPort
    });

    await applyWpUrl(wpConfigPath, localUrl);
  }

  await clearTunnelState(paths);
}

export async function restoreStaleTunnel(config, paths) {
  if (!await hasTunnelState(paths)) {
    return false;
  }

  await restoreLocalUrl(config, paths);
  return true;
}
```

```js
import path from 'path';

import { startTunnel } from '../lib/tunnel.js';
import { restoreLocalUrl, writeTunnelState } from '../lib/tunnel-state.js';
import { applyWpUrl } from '../lib/wordpress.js';

export default async function runTunnelSession({ config, paths, url }) {
  const wpConfigPath = path.join(paths.wordpress, 'wp-config.php');

  if (!await fs.pathExists(wpConfigPath)) {
    throw new Error('wordpress/wp-config.php not found. Run "noduscm generate" first.');
  }

  let interrupted = false;
  let stopWaiting = () => {};
  const onSignal = () => {
    interrupted = true;
    stopWaiting();
  };
  process.once('SIGINT', onSignal);
  process.once('SIGTERM', onSignal);

  const port = getTunnelTargetPort(config, config.engine);
  const spinner = ora(`Starting ngrok tunnel to port ${port}...`).start();
  let tunnel = null;
  let stateWritten = false;

  try {
    tunnel = await startTunnel({ port, url });
    await writeTunnelState(paths, { url: tunnel.url, startedAt: new Date().toISOString() });
    stateWritten = true;
    await applyWpUrl(wpConfigPath, tunnel.url);

    spinner.succeed(chalk.green(`ngrok tunnel ready (local port ${port})`));
    console.log(chalk.bold('\n  Public URLs\n'));
    console.log(`    Site:         ${chalk.white(tunnel.url)}`);
    console.log(`    Admin:        ${chalk.white(`${tunnel.url}/wp-admin`)}`);
    console.log(chalk.gray('\n  WP_HOME/WP_SITEURL now point to the tunnel.'));
    console.log(chalk.gray('  Press Ctrl+C to close the tunnel and restore the local URL.\n'));

    if (!interrupted) {
      await new Promise((resolve) => {
        stopWaiting = resolve;
        tunnel.exited.then(resolve);
      });
    }

    if (!interrupted) {
      console.log(chalk.red('\n  ngrok stopped unexpectedly.'));
      process.exitCode = 1;
    }
  } catch (error) {
    spinner.fail(chalk.red('Tunnel session failed'));
    throw error;
  } finally {
    process.off('SIGINT', onSignal);
    process.off('SIGTERM', onSignal);

    if (tunnel) {
      await tunnel.stop();
    }

    if (stateWritten) {
      await restoreLocalUrl(config, paths);
      console.log(chalk.gray('\n  Tunnel closed. Local WP_HOME/WP_SITEURL restored.'));
      console.log(chalk.gray('  Containers are still running ("noduscm down" to stop them).\n'));
    }
  }
}
```

````
```bash
# Random ngrok URL (free plan)
noduscm up --tunnel

# Fixed domain (paid plan)
noduscm up --tunnel-url https://my-site.ngrok.app
```

Requirements: `ngrok` installed and authenticated (`ngrok config add-authtoken <token>`).

While the tunnel runs, `up` stays in the foreground and prints the public URLs. On `Ctrl+C` it stops the tunnel and restores the local `WP_HOME`/`WP_SITEURL`; containers keep running (`noduscm down` stops them). If the process was killed abruptly, the next `noduscm up` or `noduscm down` restores the local URL automatically.

You can also store the fixed URL in `.noduscm.json` (used when `--tunnel` is passed):

```json
{
  "tunnel": { "url": "https://my-site.ngrok.app" }
}
```

- Only `wp-config.php` constants are rewritten; absolute URLs stored inside the database keep pointing to the local domain.
- On Docker with Traefik, `up --tunnel` publishes an extra Apache port (`8088:80`) so the tunnel can reach it; plain `up` removes it again.
- ngrok's free plan shows an interstitial page on the first visit and allows a single agent session.
````
